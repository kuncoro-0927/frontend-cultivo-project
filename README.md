🌿 Cultivo – Platform Pemesanan Tiket Agrowisata
Pemenang "Best Project – Kategori Web Non-Merge" di Infinite Learning.
Solusi web lengkap untuk eksplorasi dan reservasi pengalaman agrowisata.

🏆 Pencapaian
Proyek ini terpilih sebagai Project Terbaik dalam program magang dan studi independent di Infinite Learning. Penilaian didasarkan pada kualitas arsitektur kode, inovasi desain UI/UX, fungsionalitas sistem yang kompleks, dan presentasi hasil akhir.

🚀 Ringkasan
Cultivo adalah platform pemesanan tiket agrowisata di Indonesia. Fokus utama pengembangan saya dalam proyek ini adalah menciptakan alur pemesanan tiket (booking flow) yang efisien, manajemen status tiket, dan integrasi sistem pembayaran yang aman.

✨ Fitur Utama
- Optimasi 5-Step Booking Flow: Alur pemesanan tiket yang intuitif untuk meningkatkan tingkat konversi pengguna.
- Global State Management (Context API): Mengelola state global untuk autentikasi, wishlist, dan notifikasi secara ringan tanpa beban performa.
- Integrasi Payment Gateway: Terhubung penuh dengan Midtrans untuk pembayaran tiket secara real-time.
- Data Visualization & Management: Menyajikan riwayat transaksi dan manajemen tiket aktif yang responsif serta mudah dipahami.

🛠️ Tech Stack
- Frontend: React.js, Tailwind CSS
- State Management: React Context API
- Backend Integration: Express.js, MySQL, Axios Interceptors
- API Pihak Ketiga: Midtrans Payment Gateway, OAuth (Google Login)
